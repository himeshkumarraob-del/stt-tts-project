# Phase 3: Pronunciation Assessment — Methodology Audit & Completion Report

## 🎯 Phase Goals & Scope
Implement a transparent, modular Pronunciation Assessment pipeline. The system takes a target text prompt and user audio recording, performs sequence alignment and acoustic analysis, scores word pronunciation, identifies omissions/substitutions, accounts for acceptable Indian-English accent variations, and calculates an overall composite score.

---

## 🔍 Methodology Audit Findings

### 1. Phoneme Scoring Nature (Derived vs Genuine Sub-Word Alignment)
- **Finding**: The phoneme-level scores are **derived** from the word-level acoustic posterior probabilities generated by `faster-whisper` (`base.en`), mapped onto constituent phonemes using the CMU/G2P lexicon.
- **Transparency Action Taken**: 
  - Explicitly marked all phoneme assessment objects with `is_derived = true`.
  - Added documentation and API metadata (`phoneme_methodology: "word_posterior_mapped_to_lexicon_phonemes"`).
  - Clarified that timestamps correspond to word boundaries rather than independent sub-word forced alignment boundaries.

### 2. Acoustic Evidence vs Text-Only Scoring
- **Finding**: Scoring is **not** derived from transcript text alone. The model extracts true acoustic posterior probabilities (`w.probability` in range `[0.0, 1.0]`) from the neural speech model.
- **Test Verification**: Added `test_acoustic_evidence_directly_modulates_score` proving that identical matching text with degraded acoustic probability (0.50 vs 0.95) directly reduces the pronunciation score from `95.0` to `50.0`.

### 3. Word Alignment Engine
- Uses global dynamic sequence alignment (`DynamicTimeWarpingAligner` / Needleman-Wunsch DP) to align target and recognized spoken words, distinguishing between:
  - `MATCH` (`correct` or acoustic score)
  - `SUBSTITUTION`
  - `OMISSION` (score = 0.0)
  - `INSERTION` (extra word detected)

### 4. Indian-English Tolerance Rules
- Rather than marking phonetic substitutions as outright errors, an equivalence matrix (`INDIAN_ENGLISH_PHONEME_EQUIVALENCES`) checks for non-pathological Indian-English variations (e.g. `/v/` vs `/w/`, dental plosives `/dh/` vs `/d/`).
- Valid variants receive an `acceptable_variant` classification with a capped score (`85.0`) instead of punitive substitution penalties (`40.0`).

### 5. Overall Pronunciation Score Formula
$$\text{Overall Score} = \frac{1}{N} \sum_{i=1}^N \text{WordScore}_i$$
where $\text{WordScore}_i \in [0.0, 100.0]$ is derived from acoustic confidence, alignment operation penalties, and Indian-English equivalence modifiers.

## ⚠️ Important Methodological Note
- The composite pronunciation score (0–100) is an **engineering metric** based on acoustic posterior probabilities, sequence alignment penalties, and phonological distance. It does NOT claim human-level accuracy or validated clinical pronunciation grading without evaluation against a labeled human-annotated dataset.
